# Exploratory run on SYNTHETIC data

These files come from simulated (mock) models. They test the pipeline. They are NOT study results and say nothing about real AI models.

- `amplify_world/`: a world where logic really helps catch AI errors (planted effect)
- `null_world/`: a world where catching AI errors does not depend on logic (no effect)
- `validation/`: Monte Carlo check of false-positive rate and power

`run_SHA256SUMS.txt` in each world folder lists the checksums of the full original run.
`SHA256SUMS.txt` here covers every file in this folder.
